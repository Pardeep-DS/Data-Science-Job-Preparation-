# Data Science Interview Preparation Kit

A complete, self-contained set of question-and-answer guides covering every stage of a Data Science hiring process — from the initial aptitude test to the final HR round. Each file is a standalone PDF with worked answers, explanations, and practical tips.

## 📂 Contents

| # | File | Round | Description |
|---|------|-------|-------------|
| 1 | `Data_Science_Aptitude_QA.pdf` | Aptitude Test | Core Q&A covering Quantitative Aptitude, Logical Reasoning, Data Interpretation, Probability & Statistics, and SQL/Technical basics. |
| 2 | `Data_Science_Aptitude_QA_Set2.pdf` | Aptitude Test | A second, fully distinct set of aptitude questions — expands coverage with different problems across the same topic areas plus a Statistics & ML Fundamentals section. |
| 3 | `Data_Science_Technical_Interview_QA.pdf` | Technical Round | Foundational technical interview prep — Python & Programming, Statistics & Probability, ML Algorithms, Model Evaluation, SQL, and Scenario-based questions. |
| 4 | `Data_Science_Advanced_Technical_Interview_QA.pdf` | Technical Round (Advanced) | Higher-difficulty follow-up questions — Advanced ML & Deep Learning, Causal Inference, NLP & Time Series, MLOps & System Design, Advanced SQL/Big Data, and senior-level case studies. |
| 5 | `Data_Science_HR_Interview_Round_QA.pdf` | HR / Final Round | Behavioral (STAR method), motivation & career goals, data science situational/ethics questions, resume/project deep-dives, and smart questions to ask the interviewer. |
| 6 | `Data_Science_Advanced_HR_Interview_QA.pdf` | HR / Final Round (Advanced) | Tougher panel-style questions — pressure & self-reflection, leadership & ownership, curveball questions, advanced ethical scenarios, offer/negotiation questions, and addressing fresher profile gaps. |
